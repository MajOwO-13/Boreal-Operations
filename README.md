# BOREAL — Operations Division

Starter site for CASE 2512-26.

## Before publishing

Open `index.html` and replace:

`YOUR_GOOGLE_FORM_LINK_HERE`

with the real link to the Google Form.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - index.html
   - style.css
   - script.js
   - boreal-banner.png
3. Go to Settings → Pages.
4. Under Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
5. Save.
6. GitHub will give you a public URL.
